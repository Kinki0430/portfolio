專題介紹

傳統租屋網站大多需要使用者自行設定租金、地區、 房型等明確條件，但實際租屋時， 使用者也常會出現「租金不要太高」、「離學校近一點」、 「生活機能好」等較口語且模糊的需求。

因此本專題嘗試將自然語言需求轉換為系統可處理的資訊， 再透過五項租屋決策評估因子與偏好權重， 計算不同租屋物件與使用者需求之間的符合程度。

兩種使用模式

一般條件篩選

使用者依租金、地區、房型等明確條件進行設定， 系統直接從租屋資料中篩選並顯示符合條件的房屋。

自然語言推薦

使用者可直接以文字描述租屋需求， 系統解析需求後計算各項評估因子的符合程度， 再產生個人化推薦排序。

自然語言推薦流程

  1. 輸入需求 使用自然語言描述租屋需求
  2. 需求解析 轉換成結構化需求資料
  3. 模糊量化 計算各因子 0～1 符合程度
  4. 偏好權重 依重要性排序建立權重
  5. 推薦排序 計算人房適配度並排序

OpenAI API 主要負責理解並整理使用者輸入的自然語言需求， 實際的符合程度與推薦結果則由系統中的計算方式產生。

五項租屋決策評估因子

預算租金

根據使用者可接受的租金範圍， 評估房屋租金與需求之間的符合程度。

通勤便利度

將租屋地址轉換為經緯度， 並與使用者選擇的固定目的地計算直線距離。

生活機能

依租屋周邊生活設施資料， 評估日常生活便利程度。

設備完善度

根據房屋提供的基本設備項目， 評估設備完整程度。

採光與通風

根據房屋是否具有對外窗、陽台等資訊， 評估採光與通風條件。

核心機制

模糊量化：「租金不要太高」怎麼計算？

例如設定月租 8,000 元以下完全符合需求， 10,000 元以上則不符合。 若某房源月租為 9,000 元， 則可透過隸屬函數計算其符合程度：

(10000 − 9000) ÷ (10000 − 8000) = 0.5

此範例主要用來說明計算方式， 實際參數將依租屋資料分布進行設定與調整。

人－房適配度怎麼計算？

將五項評估因子的符合程度乘上各自的偏好權重， 再透過加權加總得到整體人－房適配度。

公式： S = w₁μ₁ + w₂μ₂ + w₃μ₃ + w₄μ₄ + w₅μ₅

其中權重總和為 1。 人－房適配度越高， 代表該租屋物件越符合使用者整體需求。

五項評估因子的資料來源
因子 原始資料
預算租金 每月租金
通勤便利度 地址轉經緯度，計算與固定目的地的直線距離
生活機能 租屋周邊生活設施資料
設備完善度 冰箱、冷氣、衣櫃、書桌等設備資訊
採光與通風 是否具有對外窗與陽台
偏好權重怎麼建立？

使用者可以自行設定五項租屋決策評估因子的重要性排序， 系統再依排序建立個人偏好權重。

若使用者未自行設定， 則採用 114 份問卷調查結果建立預設權重。 問卷中第一至第五順位分別給予 5、4、3、2、1 分， 再將各因子的累積得分正規化為權重。
